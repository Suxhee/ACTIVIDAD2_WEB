# Actividad 2 - Programación Web

## Cómo ejecutar el Ejercicio 1

Abrir **dos terminales**.

Terminal 1 (backend):

```bash
cd EJERCICIO1/BACKEND
npm install
npm run dev
```

Terminal 2 (frontend):

```bash
cd EJERCICIO1/FRONTEND
npm install
npm run dev
```

Abrir en el navegador la dirección que muestra Vite (http://localhost:5173).

## Cómo ejecutar el Ejercicio 2

Abrir **dos terminales**.

Terminal 1 (backend):

```bash
cd EJERCICIO2/BACKEND
npm install
npm run dev
```

Terminal 2 (frontend):

```bash
cd EJERCICIO2/FRONTEND
npm install
npm run dev
```

Abrir en el navegador la dirección que muestra Vite (http://localhost:5173; si el Ejercicio 1 sigue corriendo, Vite usará otro puerto como 5174).

> El backend debe estar encendido antes de abrir el frontend, si no aparecerá un mensaje de que no se pudo conectar.
